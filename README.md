## 🚀 Flagship Projects

### 🧠 [BaseMind](https://github.com/shivamsingh7533/BaseMind) — Autonomous AI Customer Support & RAG Platform

Production-grade **multi-tenant AI SaaS** that bridges hallucination-free generative AI with human support teams.

- Grounded **Google Gemini 2.5** RAG engine (PDF/TXT/CSV/MD ingestion + web crawler)
- **pgvector** 768-dim cosine search with real-time citations
- **Human-in-the-Loop** live takeover console (bot pause → operator claim → handback)
- Slack & Discord bots, embeddable chat widget, Lead CRM, Clerk JWT auth, B2 storage
- <a href="https://base-mind.vercel.app/">Live Demo</a>

> **Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Clerk · FastAPI · Python 3.12 · PostgreSQL (Neon) · pgvector · Google Gemini · Backblaze B2 · Vercel · Render
